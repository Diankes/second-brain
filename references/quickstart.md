# Quickstart: using second-brain without thinking about it

You don't need to know SQL, tags, or the entry templates. That's Claude's job. This page is
the whole cheat sheet — the [README](../README.md) is the technical reference underneath it, for
when you're curious how it works.

## What happens with zero effort from you

- Every message you send is recorded automatically.
- When a session ends, or gets compacted because it's grown long, that's recorded too, along
  with a snapshot of the database.
- Every so often, Claude will pause to jot down a proper note before moving on — that's the
  system keeping the memory worth reading later, not something you need to ask for.

You can just talk normally. Nothing above needs a command.

## The handful of things worth saying out loud

- **"Log that as an insight"** (or *decision*, or *reading*) — when you land on something worth
  keeping precisely, say so and Claude will write it up properly, in the right place.
- **"Resume where we left off on X"** — Claude will pull up the relevant history and pick the
  thread back up instead of starting cold.
- **"What's still open on X?"** — surfaces the open questions nobody's answered yet.
- **"Show me what's in memory so far"** — a quick tour of what's been captured.

## The one thing to remember

You never need to know the schema, the tags, or the exact wording of a template. Just say
"remember this" or "resume that" when it matters, and Claude handles the mechanics.
